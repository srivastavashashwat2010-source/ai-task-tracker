# AI Student Task Tracker

## 📌 Project Description

This is a simple **AI-based task management system** built using Python and Streamlit.
It helps students organize their daily tasks, track progress, and get AI suggestions for better study planning.

---

## 🎯 Objectives

* To help students manage tasks efficiently
* To learn integration of AI in real-world applications
* To build a simple and interactive GUI using Streamlit

---

## 🛠️ Technologies Used

* Python
* Streamlit
* OpenAI API
* Pandas

---

## ⚙️ Features

* Add new tasks with deadline and priority
* View all tasks in a table
* Mark tasks as completed
* Track overall progress
* AI assistant for study help

---

## 📂 Project Files

ai.py              # Main application
tasks.csv          # Stores tasks
requirements.txt   # Required libraries
README.md          # Documentation

---

## ▶️ How to Run the Project

### Step 1: Install dependencies

"
pip install -r requirements.txt


### Step 2: Add your API key

Edit 'ai.py':


client = OpenAI(api_key="YOUR_API_KEY")


### Step 3: Run the app

streamlit run ai.py


---

## 📊 Output

* A web-based interface will open in your browser
* You can add tasks and interact with AI assistant
